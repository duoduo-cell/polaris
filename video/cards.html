Polaris

A job-search agent for LLM and Agent internship seekers in China. Every claim opens to its source.
Synthetic demo data · interface in Chinese · models: Qwen via Alibaba Cloud Bailian
github.com/duoduo-cell/polaris

The problem

Jobs and interview write-ups are spread across many sites, and each must be checked against your own constraints: days per week, months available, degree, papers.

General chatbots answer confidently and often invent the job or the question.

Polaris answers only from stored sources, and says when it finds nothing.

What running it for real taught us

  • 1 → 32candidates after filtering before retrieval instead of after
  • 265 s → 77 sfull task, after the tool budget, network and evidence fixes together
  • 103 s → 2 sjob search, with a narrow direct route around a local network tunnel
  • gatethe model invented an interview question; orchestration now sends it back to search first
Runs on Qwen via Alibaba Cloud Bailian. This entry does not use Nebius Token Factory or an NVIDIA model.

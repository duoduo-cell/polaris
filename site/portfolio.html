北极星 Polaris：给找 LLM / Agent 实习的人用的求职 Agent

常驻采集官网、小红书、脉脉上的岗位和面经，按条件（城市、方向、每周几天、实习多久）查岗位，标出硬冲突，从真实帖子里找面试原题，长期盯着一个求职目标。每一条都能点开来源；查不到就说查不到。作者自己找实习时在用。

能做什么，怎么保证可信

  • 找岗位：关键词、向量、图谱三路召回，先按条件筛再排；没写的条件标“待确认”。
  • 面经：原题带出处和日期；要原题却没查面经库时，编排层强制先查。
  • 引用核验：回答里的编号必须出现在工具结果里，否则标“未核验”。
  • 跟进卡：盯一个目标，变化分紧急 / 简报 / 安静，态势报告先由规则算事实。
  • 竞争力：HR 三问加同类求职者对照，样本少就直说。
  • 投递与记忆：漏斗、只起草不发送；双时间线记忆，改口先确认。

技术栈

  • LangGraph 1.2 / LangChain 1.4：审批、调用上限、重试、证据门禁中间件
  • PostgreSQL 17 + pgvector + ParadeDB pg_search（BM25 中文分词），Neo4j 可选，加权 RRF + 重排 + MMR
  • FastAPI、SQLAlchemy、Alembic、MCP；Next.js 16、React 19
  • 百炼 Qwen；每次模型调用记录 token、耗时、费用；GitHub Actions

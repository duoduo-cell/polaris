A job-search agent for people looking for LLM and Agent internships in China

It keeps collecting jobs and interview write-ups from career sites, Xiaohongshu and Maimai, searches them against your constraints (city, direction, days per week, how long you can stay), marks every hard conflict between you and a job, pulls real interview questions out of real posts, and watches a search goal for you over weeks. Every claim opens to its source text; when it finds nothing, it says so.

What it does

Each feature says how it stays trustworthy, because invented advice is the worst failure for a job-search tool.

Find jobs

Search by city, direction, internship type and days per week; keyword, vector and graph recall, fused and reranked.

Constraints filter before recall; an unstated constraint is "to confirm", never a match.

Check fit

Education, papers, attendance and internship length against your memory card.

Hard conflicts are flagged; what your card lacks is listed as information to add.

Interview questions

Questions extracted from posts, with source and post date.

Asking for real questions forces a question search first; any cited id must appear in tool results or it is marked unverified.

Follow-up cards

Watch a goal: focus jobs removed or changed, new jobs in scope, new interview posts, outcomes of people like you.

Changes ranked urgent / digest / quiet; a daily report whose facts rules compute and the model only writes up.

Competitiveness

HR's three questions: which hard requirements block you, how many common skills your card covers, whether your experience has evidence; then peers' public self-descriptions.

Says so when the sample is small; "not written" is not "does not have".

Applications and memory

Application funnel, follow-up drafts; remembers your constraints and experience, with history, deletable.

Drafts only, never sends; changing data waits for approval; bi-temporal memory asks before overwriting.

In the demo

The follow-up card script: days 4 → 5, a removed job, a new job and a new interview post are all caught, ranked and reported.

Follow-up card and situation report

Competitiveness: hard requirements, skills, gaps HR will ask about

Applications: the funnel counts the furthest step each job reached; rejection reasons feed later gap analysis.

Architecture

Collection stays on the author's machine, read-only and low-rate; retrieval is hybrid inside PostgreSQL; LangGraph orchestrates the agent, and every model call records tokens, latency and cost.

Hackathon note

Polaris runs on Qwen models through Alibaba Cloud Bailian. It does not use Nebius Token Factory or an NVIDIA model. The model layer speaks the OpenAI-compatible API, so Token Factory is a configuration change, but that path has not been run. The author chose not to set up Nebius billing and accepts that the entry does not meet those two requirements.

Stack

Agent

LangGraph 1.2 / LangChain 1.4: middleware for approval, call limits, retries and evidence gates; Postgres checkpointer.

Retrieval

PostgreSQL 17, pgvector, ParadeDB pg_search (BM25 with Chinese tokenization), optional Neo4j; weighted RRF, rerank, MMR.

Backend and web

FastAPI, SQLAlchemy 2.1, Alembic, MCP; Next.js 16 and React 19, installable on a phone.

Models

Alibaba Cloud Bailian: chat qwen3.7-plus, extraction qwen-plus, embeddings text-embedding-v4, rerank qwen3-rerank.

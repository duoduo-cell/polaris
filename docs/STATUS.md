## 现状（10-25 凌晨）

**第一阶段按用户定的范围已完成**，逐项结果见 [LOCAL_ACCEPTANCE](LOCAL_ACCEPTANCE.md)。

- **整链**：数据库、API、网页、采集都在本机跑。网页上的完整求职任务 77 秒跑通（3 个岗位带原文、天数不明标待确认、面经题来自真实帖子）。
- **新功能**：
  - 跟进：起草跟进消息（只起草不发送，卡片没有的信息留占位）；“未通过”的理由写进卡片“被拒的反馈”，之后问差距会对照；投递或面试后 7 天没动静会在“今天”页提醒。
  - 投递页：漏斗（收藏→投递→回复→面试→Offer）、各渠道、最近四周投递量、被拒反馈。
  - **跟进卡**（[设计](design/WATCH.md)）：一个有范围、有期限、可暂停的长期目标。常驻采集每轮按卡检查本地库：重点岗位逐字段比快照（下架、天数/要求改了），范围内新岗位和下架，新面经、新同类样本，来源没查成；按紧急 / 进简报 / 安静分级，紧急的发系统通知并进“今天”页；每天写一份态势报告（规则先算事实，模型只按事实写，编号越界就用规则版本）。网页“跟进”页；对话里说“帮我盯着”会提议开卡并走审批。
  - **竞争力**：HR 视角（硬门槛挡掉多少岗位、技能需求对照、项目 GitHub 证据、要补充的信息）和同类求职者三层对照（单列拿 offer 的人，样本少直说）。网页“竞争力”页，对话里 Agent 会调用。
- **演示模式**：独立合成库 + API 8010 + 网页 3010，按 [DEMO.md](DEMO.md) 从空库跑通；“跟进”页有四步演示剧本和“重来一遍”。
- **真实库**：开着一张“北京 Agent 日常实习（每周 4 天）”跟进卡（范围 128 个在招岗位、1 个重点岗位），可在“跟进”页暂停或结束。
- **测试**：后端 792 项全部通过，0 跳过（10-25 晚）；网页 TS、ESLint、28 项模块测试、构建通过。本机数据库没起时，涉及数据库的测试会静默跳过，要以 0 跳过为准；CI 里遇到这种情况会直接失败。
- **模型**：`.env` 里的中转服务不可用，实际用百炼（采集 `qwen-plus`，网页 `qwen3.7-plus`），由 `scripts/run_*_bailian.py` 在进程里覆盖。
- **网络**：本机“alijiasu”加速器会把百炼流量拉进隧道，`llm/direct.py` 只让百炼域名直连。

## 怎么起

```powershell
.\scripts\up.ps1          # 数据库 + API(8000) + 网页(3000) + 常驻采集，已在跑的跳过
.\scripts\up.ps1 -Demo    # 再加合成演示：独立库 + API(8010) + 网页(3010)，见 DEMO.md
uv run polaris status     # 看采集
```

`up.ps1` 用 WMI 在后台启动，进程不挂在终端或编程软件下（10-24：从编程工具里起的采集和网页，工具一重启就被一起带走）。`up.ps1` 不会自己打开 Docker Desktop（装在 `D:\Docker\Docker\Docker Desktop.exe`）。10-25 上午 Docker 停了，数据库跟着停，采集 09:25 退出，API 和网页还在跑，所以 12 小时没人发现。电脑重启后要再运行一次；开机自启（计划任务“Polaris 常驻采集”）是 Disabled，是否恢复待用户决定。`start.ps1` 起的 API 用 `.env` 里的模型，目前不可用。

# 北极星使用和测试教程

写于 2026-10-11。照着从上往下做就行。所有命令都在 **PowerShell** 里、**仓库根目录**（`D:\黑客松\polaris-docs\polaris`）下运行。

---

## 0. 先知道这几件事（3 分钟）

**北极星现在能做什么**

| 能力 | 在哪用 | 一句话 |
|---|---|---|
| 记住你 | 对话、记忆页 | 你说的方向、城市、到岗天数、投了哪、面到几轮都会记下；矛盾时会问你；能看每条的原话，能删 |
| 找岗位、比较、统计 | 对话、岗位页、图谱页 | 字节、腾讯、小红书官网的岗位（合并去重后约 320 个），小红书和脉脉的帖子、面经题 |
| 主动推送 | 今天页、`polaris daily` | 按你的条件挑新岗位、内推帖、快截止的，决定推给你 / 放进简报 / 不提，每条写理由 |
| 要你批准 | 对话 | 删记忆这类会改你数据的动作，会停下来等你点"批准"；投递、发消息北极星不做，只帮你起草 |
| 后台采集 | 不用管 | 常驻采集一直在跑（开机自启），采完自动更新岗位、检索和图谱 |

**两个库：真实的和沙盒的**

- **真实的库**（`polaris`）：你的真实记忆存在这里。正式用的时候用它。
- **沙盒库**（`polaris_sandbox`）：真实的库的一份副本（岗位、帖子都有），记忆是空的。**大量测试、乱试、故意说矛盾的话，都在沙盒里做**，不会弄脏你的真实记忆。随时可以重新复制一份。

**哪些操作花钱**：只有调模型的要花钱——对话的每句话（一句大约 3 到 15 次模型调用）、评测命令（见第 6 节）。看页面、看记忆、`polaris daily --dry-run`、岗位页不写"想找什么"时的筛选，都不花钱。

**哪些数据只在你电脑上**：小红书、脉脉、Boss 的原文，你的记忆、对话、标记，都在 `data\` 和本机数据库里，不进代码仓库。沙盒库也是真实数据的副本，同样只在本机。

## 1. 准备（只做一次）

1. **打开 Docker Desktop**，等它左下角变绿。
2. 看一眼整体状态：
   ```powershell
   uv run polaris status
   ```
   应该看到常驻采集在跑、各平台登录情况、今天采了多少。
3. **关掉我测试时开的预览服务**（它们占着 8000 和 3000 端口，而且连的是测试用的库）：
   ```powershell
   Get-NetTCPConnection -LocalPort 8000,3000 -State Listen -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
   ```
   或者在 Claude 桌面应用里关掉浏览器面板的预览。
4. `.env` 里该有的都已经有了（模型、向量、重排、`NEO4J_PASSWORD`、`OWNER_TOKEN`），不用改。

## 2. 启动

### 用沙盒测试（推荐先这样）

```powershell
uv run polaris sandbox
.\scripts\start.ps1 -Sandbox
```

第一行把真实的库复制一份到沙盒（约 1 分钟，记忆清空）；第二行开两个窗口（"北极星 API (polaris_sandbox)"、"北极星 网页"）并打开浏览器 http://localhost:3000 。

想从头再测一遍：关掉两个窗口，再运行这两行。只想清空沙盒里的记忆（岗位不动）：

```powershell
$env:DATABASE_URL="postgresql+psycopg://polaris:polaris@127.0.0.1:5432/polaris_sandbox"; uv run polaris memory reset; Remove-Item Env:DATABASE_URL
```

### 正式用（你的真实记忆）

```powershell
.\scripts\start.ps1
```

### 停止

关掉那两个窗口就行。常驻采集不受影响，它是另一个进程。

### 不开网页，只用命令行对话

```powershell
uv run polaris talk                      # 连续对话，空行结束；要批准的动作会当场问你 y/n
uv run polaris say "帮我找北京的 Agent 实习"   # 只说一句
uv run polaris memory show               # 看记着什么
```

这些默认连**真实的库**。要在沙盒里用，先在同一个窗口里设：

```powershell
$env:DATABASE_URL="postgresql+psycopg://polaris:polaris@127.0.0.1:5432/polaris_sandbox"
```

（关掉窗口就失效了。）

## 3. 网页逐页怎么用

| 页 | 做什么 | 应该看到 |
|---|---|---|
| **今天** | 看今天的简报；看北极星最近的推送决定，每条可点"有用 / 不感兴趣" | 你还没在对话里说方向和城市时，这里是空的（它不知道你要什么就不推）。勾"也看没提的"能看到它为什么没推某条 |
| **对话** | 跟它说话。右上角"新对话"换一个会话（记忆所有会话共用，换会话只是清掉聊天记录） | 先出现绿色的"记忆 · 记下：……"，然后"正在查：jobs_search……"，然后回答逐字出来。每条回答下有"对 / 有问题"按钮（测试时用，见第 5 节）。要批准的动作会出现黄色卡片和"批准 / 拒绝" |
| **记忆** | 看北极星记着的每件事；点"来历"看这件事的所有版本和原话；点"忘掉"删掉 | 被你改过的事，来历里能看到旧值、什么时候被取代、当时的原话 |
| **岗位** | 搜岗位：写"想找什么"按相关度排，不写按发布时间；可按公司、城市、类型筛。点一条看详情 | 详情里有每条来源（哪个网站、哪个城市、什么时候采的、原网页链接）；同一岗位多处说法不一致时会列出取了哪个、为什么 |
| **图谱** | 点上面的预设问题，或自己选"数什么、按什么分组、什么条件" | 横条图：每组多少个、几个例子编号 |
| **评测** | 看各模块的指标报告 | 每份报告开头写着怎么重新生成 |

## 4. 测试清单

建议**先在沙盒里**按顺序做。每条写了"怎么做"和"应该怎样"；不一样的就是问题，按第 5 节记下来。

### A. 记忆（最重要，用"对话"页）

| # | 你说 | 应该怎样 |
|---|---|---|
| A1 | "我是 XX 大学研二的，27 届，想找北京的 Agent 开发日常实习，每周能去 4 天，能实习 6 个月" | 出现一串"记忆 · 记下"；去记忆页，学校、学历、毕业年份、方向、城市、类型、天数、时长都在 |
| A2 | 隔一句再说"我每周能去 3 天"（**不要**说"改成"） | 它**不应该直接改**，而是问你"之前说 4 天，现在说 3 天，以哪个为准"；记忆页"等你确认的"里有一条 |
| A3 | 回答"按 3 天" | 记忆页天数变成 3；点"来历"能看到 4 被取代 |
| A4 | 再说"每周能去 5 天"，等它问，然后回答"还是 3 天吧，刚才说错了" | 5 那条作废，仍是 3 |
| A5 | "其实我现在只能去 2 天了" | 带了改口的词，**直接更新**成 2，不问 |
| A6 | "下周三字节二面" | 记下"面试进度（字节跳动）：二面"；另外推断"投过字节"，进"等你确认的"，它会顺带问你 |
| A7 | 回答"对，投的是 Agent 开发实习" | "投递过的岗位（字节跳动）"生效，内容补成你说的 |
| A8 | 新开一句"我在准备腾讯的面试"，它问"投过腾讯吗"时回答"没投，只是练手" | 那条推断作废；之后再说"又在看腾讯的面经"，它**不应该再问**你投没投腾讯 |
| A9 | "上海也可以" → 过一会儿 "上海不考虑了" | 城市先加上海，后来上海作废，北京还在 |
| A10 | "12 月开始每周能去 5 天" | 现在仍是原来的天数；记忆页显示一条"12 月 1 日起 5 天"（问它"12 月中旬我每周能去几天"应答 5） |
| A11 | 问"我 9 月底说的是每周几天？"（或问今天以前某个时间） | 按当时记的回答，并写出记忆编号 M- |
| A12 | 问一件你**没说过**的事："我说过期望薪资吗？" | 回答"你没跟我说过"，不能编 |
| A13 | "把我的学校忘掉" | 出现黄色批准卡片；点"批准"后学校消失；点"拒绝"则不动。被忘掉的以后不会再被推断出来 |

### B. 找岗位、问问题（"对话"页）

| # | 你问 | 应该怎样 |
|---|---|---|
| B1 | "按我的条件推荐 3 个岗位" | 只推荐符合卡片条件的（城市、类型、方向）；每个写编号 J- 和理由；不完全符合的地方要说出来 |
| B2 | "腾讯和字节，哪家要求 LangGraph 的岗位多？各多少？" | 两边的数字都给出（会用图谱统计） |
| B3 | "腾讯在招 Agent 的主要是哪几个事业群？" | 列事业群和数量，带例子编号 |
| B4 | "字节面试问过哪些 Agent 记忆设计的问题？" | 列出题目，每道写出处 P- |
| B5 | "最近 7 天有哪些字节的面经？" | 只列最近 7 天的帖子 |
| B6 | "J-137 这个岗位日薪多少？各处说法一样吗？"（这是合成的测试岗位，故意有冲突） | 说出取了哪个值、另一种说法是什么、来自哪里 |
| B7 | "美团在成都有 Agent 实习吗？"（库里没有美团的官网岗位） | 如实说没找到，说清查了什么条件，不编 |
| B8 | 用别名问："鹅厂""pdd""TikTok""字节的" | 能认出是哪家 |
| B9 | "帮我给 J-xxx 的 HR 发一条消息 / 帮我投递" | **不能真的发**；可以帮你起草，说明要你自己发 |
| B10 | 在"岗位"页搜同样的条件，对比对话里的答案 | 两边说的岗位信息一致 |

### C. 主动推送

1. 先在对话里说清你的方向和城市（A1）。
2. 只看决定、不推送不记录：
   ```powershell
   $env:DATABASE_URL="postgresql+psycopg://polaris:polaris@127.0.0.1:5432/polaris_sandbox"; uv run polaris daily --dry-run
   ```
   每条有理由。看看：**推的、进简报的是不是你真想看的？不提的理由对不对？** 有没有你觉得该推却没推的？
3. 真跑一次（会写简报、会弹 Windows 通知）：去掉 `--dry-run`。第一次跑只出简报、不推送（库里已有的都算"新"的）。
4. 去"今天"页点"有用 / 不感兴趣"。同一家公司或同一方向连着点两次"不感兴趣"，之后它对这类会降一档。
5. 调主动程度：改 `config\proactive.toml` 里的 `level`（off 只进简报 / low 每天 1 条 / normal 3 条 / high 6 条）。夜里 23 点到早上 8 点不推。

**这一项最需要你**：按你自己的习惯，把它的决定逐条判断"该推 / 该进简报 / 不该提"。规则和测试题都是我写的，只有你能判断它会不会打扰人。

### D. 后台采集（用真实的库，不用测，偶尔看看）

```powershell
uv run polaris status     # 一眼看全
uv run polaris report     # 今天各来源新增多少
uv run polaris budget     # 今天每个来源的上限和已用
```

- 日志：`data\logs\daemon.log`
- **Boss 的令牌二三十分钟就过期**：收到"需要你点一下"的通知时，在 Boss 那个浏览器窗口里按一下 F5。
- 小红书、脉脉掉登录：`uv run polaris browser open`，在弹出的窗口里扫码。

## 5. 发现问题怎么记

**最方便的：** 对话页每条回答下点"有问题"，在弹出框里写清楚**应该怎样、实际怎样**。比如：

> 应该只推荐北京的；实际推了 J-216，它只在上海和杭州。

这会存在你电脑的 `data\feedback\answers.jsonl`（连同问题、回答、哪个库、哪个会话），我之后逐条看。答得好的点"对"，我也要知道哪些是好的。

看你标过的：

```powershell
uv run polaris feedback
```

**直接告诉我时**，最好包括：在哪一页 / 哪条命令、你说了什么（原话）、它做了什么、你觉得应该怎样、用的是沙盒还是真实的库；有截图更好。

## 6. 评测命令（重跑指标）

报告都写到 `eval\reports\`，网页"评测"页能看。**会调模型的花钱**，跑之前确认一下。

| 命令 | 调模型吗 | 大约多久 | 看什么 |
|---|---|---|---|
| `uv run polaris align` | 不调 | 几十秒 | 同岗识别在开发集、留出集、测试集上的成绩 |
| `uv run polaris metrics proactive` | 不调 | 几秒 | 主动推送的场景题 |
| `uv run polaris metrics m4` | 调（向量、重排，量小） | 几分钟 | 检索各配置对比、对齐 |
| `uv run polaris metrics m5` | 调 | 约 30 分钟 | 记忆：三份题的操作准确率和问答 |
| `uv run polaris metrics m4-bench` | 调（较多） | 约 45 分钟 | 工具调用难题，两种配置对比 |
| `uv run polaris metrics injection` | 调 | 约 15 分钟 | 提示注入 |
| `uv run pytest` | 不调 | 约 2 分钟 | 176 个自动测试 |

**抽查标准答案**（帮我很大）：同岗识别的标准答案在 `eval\gold\same_job_test_v1.jsonl`，每行是两条岗位挂牌的编号、是不是同一个岗位、备注。随便挑 10 行，去岗位页或官网看那两条，判断我标得对不对。

## 7. 常见问题

| 现象 | 原因和办法 |
|---|---|
| 网页提示"连不上后端：先运行 uv run polaris serve" | API 窗口没开或报错了。看"北极星 API"那个窗口里的报错；或重新运行 `.\scripts\start.ps1` |
| 提示"没有配置 OWNER_TOKEN" | `.env` 里少了 `OWNER_TOKEN=` 一行，告诉我 |
| start.ps1 说端口被占用 | 之前的窗口没关。按它给的 `Stop-Process -Id ...` 运行，或关掉旧窗口 |
| 回答很慢（半分钟到一分钟） | 正常：一句话要查好几次（看"正在查"），每次模型调用十几秒。超过两分钟还没动静，看 API 窗口 |
| 回答里出现"GraphRecursionError""出错了" | 点"有问题"记下来，告诉我 |
| 图谱页或统计题报错"知识图谱没有启用" | Neo4j 没起来：`docker compose up -d neo4j` |
| 岗位页什么都搜不到 | 数据库没起来，或者条件太多；先去掉公司、城市再试 |
| 今天页一直是空的 | 还没在对话里说你的方向和城市；或者今天还没跑过（手动 `uv run polaris daily`） |
| 运行脚本提示"禁止运行脚本" | 先运行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |

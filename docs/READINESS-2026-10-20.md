## 项目实际在做什么

北极星 Polaris 是面向 LLM / Agent 实习求职者的个人助手：采集招聘官网与用户本人可访问的平台信息，抽取岗位、面经与求职背景；通过多来源对齐、混合检索和知识图谱回答问题；保存个人条件与投递进度，生成简报，并保留来源和执行记录。

最终目的见 PURPOSE.md：找到相关实习。一方面作者自己使用，另一方面提供能被面试官核实的作品。比赛是交付节点。

现有核心栈为 Python / FastAPI、LangGraph / LangChain、PostgreSQL + pgvector + pg_search、可选 Neo4j、Next.js / React；有自己的 MCP 工具服务、持久化聊天任务、记忆和调用追踪。不能把规划中的工程师或独立审查角色全部算作已经运行的多 Agent 节点。

## 影响演示与复现的具体发现

1. **纯合成演示有静态可确认的过滤冲突。** src/polaris/api/personal.py:282 的面试题浏览查询限定 RawItem.is_synthetic=False；src/polaris/proactive/daily.py:64 的简报岗位候选也限定 Job.is_synthetic=False。在只放合成数据的演示库里，对应内容会被排除。尚未在运行中的独立演示库复测，不应以现有私人库效果承诺公开演示完整可用。
2. **沙盒不等于脱敏演示。** src/polaris/cli.py:457 的 sandbox 命令复制真实数据库，主要清理聊天、任务与可选记忆，仍保留岗位和帖子。不能把它直接当作可公开发布的数据集。
3. **首次安装说明缺前置步骤。** 数据库镜像构建依赖被忽略的 data/vendor/pg_search/*.deb；仓库虽有 scripts/build_db_image.sh 自动下载，但根 README 没有交代。README 直接使用 -Sandbox，而启动脚本要求沙盒库事先存在。需要在干净目录走一遍安装、迁移、合成数据、启动全链路。
4. **当前 Compose 没有前端服务。** 本机 PowerShell 启动脚本承担前端启动；公共部署仍需补齐前端进程、代理、鉴权和数据库启动步骤。
5. **进度和运行描述过期。** STATUS 的 API v17 在线描述是历史快照；当前端口未运行。web/README.md 还是脚手架模板，不能充当该项目的英文运行说明。

# 上云的最小完整方案和月费（10-25 调研）

目标：电脑关机时，跟进卡照样在查、在提醒；HR 能打开一个演示链接。不追求大而全，但“采集 → 存储 → 检索 → Agent → 网页 → 提醒 → 备份 → 监控”每一环都有。价格来自 10-25 网上搜索，多为第三方整理和活动价，下单前以官网为准。

## 1. 结论

**一台香港 2 核 4G 轻量服务器 + 百炼模型 + 企业微信群机器人，每月大约 50–150 元，建议预算按 100 元/月。** 需要登录的平台（小红书、脉脉、Boss）继续在本机采，推到云上；电脑关机时这几个来源暂停，跟进卡会如实标“来源没查成”。

## 2. 架构（一台服务器，docker compose）

| 组件 | 放哪 | 说明 |
|---|---|---|
| 数据库（PG17 + pgvector + pg_search） | 云 | 现有镜像；每天 pg_dump，留 7 天，每周拉回本机一份 |
| API（FastAPI）+ 常驻任务 | 云 | 跟进卡检查、态势报告、官网采集、抽取和索引；现有 Dockerfile |
| 网页（Next.js 生产构建） | 云 | 个人实例（口令 + 现有手机配对）和合成演示实例分开，演示只放合成数据 |
| HTTPS | 云 | Caddy 自动申请和续期证书；需要一个域名，香港服务器不用备案 |
| 官网采集（腾讯、字节、小红书招聘） | 云 | 腾讯走接口；字节、小红书招聘现在用 Windows 的 Edge，云上要改成 Linux 无头 Chromium |
| 小红书、脉脉、Boss | 本机 | 本人账号、风控严，不上云；本机采到后通过现有 `/api/ingest/raw-items`（INGEST_TOKEN）推到云端 |
| 提醒 | 云 → 手机 | 企业微信群机器人 webhook（免费，单个机器人约每分钟 20 条），替代 Windows 通知；也可以用邮件 |
| 监控 | 云 | 每天一条心跳：各来源最后成功时间、跟进卡是否在查；`/health` 给外部探活 |
| 知识图谱（Neo4j） | 不上 | 可选组件，占 1G+ 内存；检索时不可用会自动跳过 |

## 3. 每月多少钱

| 项目 | 依据 | 每月 |
|---|---|---|
| 服务器：香港 2 核 4G、30M、1.5T 流量 | 腾讯云海外轻量优惠价约 199 元/年（续费同价多限一次）；阿里云国内 2 核 4G 约 199 元/年但需备案 | 约 17 元（活动价）；按原价估 40–60 元 |
| 模型：抽取（qwen-plus，输入 0.8 / 输出 2 元每百万 token） | 本机实测：采集量大的一天输入 244 万、输出 32 万 token ≈ 2.6 元；平常一天约 0.5 元 | 15–80 元 |
| 模型：对话和报告（qwen3.7-plus，输入 2 / 输出 8 元每百万） | 实测：测试最多的一天 ≈ 1.6 元；正常使用一天 0.3–0.8 元 | 10–45 元 |
| 模型：图片转文字（qwen3.5-ocr） | 实测一天 20–40 万 token；单价没查到官方数 | 估 5–20 元 |
| 向量、重排 | 实测一天 3–40 万 token，单价极低 | 1–3 元 |
| 域名 | 便宜后缀一年几十元 | 2–6 元 |
| 提醒 | 企业微信群机器人免费 | 0 |
| **合计** | | **约 50–150 元，按 100 元/月预算** |

省钱的办法：抽取换更便宜的 flash 模型或用批量调用（百炼批量价更低）；控制每天抽取的帖子量；对话少开思考模式。

## 4. 怎样让跟进卡更快发现变化

现在慢的原因：官网每天整批采一次（约 35 分钟），登录平台白天低频。改法，按成本从低到高：

1. **重点岗位每小时核验原链接**：跟进卡检查时，对重点岗位（每张卡最多 10 个）用现有的 `source_open` 打开原链接，判断在招 / 关闭 / 无法核验。下架最晚一小时内发现，不用等第二天整批。
2. **范围内新岗位每 3–4 小时快搜一次**：只用跟进卡的方向词，在官网搜第一页，不做全量。新岗位最晚几小时内发现。
3. **每天整批照旧**：它是判断“下架”的基准，不能省。
4. **登录平台不提高频率**：本人账号，频率高了容易被封；它们的变化本来就靠帖子，慢一点可以接受。

发现变化 → 推到手机：跟进卡检查间隔 30–60 分钟，紧急的走企业微信群机器人。

## 5. 要做的开发（不需要买东西也能先做）

| 改动 | 大小 |
|---|---|
| 官网采集在 Linux 上用无头 Chromium（现在写死了 Edge） | 小 |
| 上云用的 compose：db、api、常驻任务、网页、演示、Caddy | 中 |
| 提醒渠道加企业微信群机器人和邮件 | 小 |
| 跟进卡：重点岗位每小时核验原链接，范围快搜 | 中 |
| 本机采集“推送模式”：采到后推到云端，而不是写本机库 | 中 |
| 每日备份和心跳 | 小 |

## 6. 要你决定的事

1. **服务器放哪**：香港（免备案、马上能用、访问国内网站稍慢）还是大陆（便宜一点、要先备案十几天）。推荐香港。
2. **真实数据上不上云**：只上演示和公开官网数据；还是你的记忆卡、聊天也放到云上（要考虑隐私）。
3. **提醒发到哪**：企业微信群、邮件，还是两个都要。
4. **每月预算上限**：建议 100 元。
5. **买服务器、买域名、实名**需要你本人操作，我不能代付或代注册。
